La sicurezza in {{BRAND}}

Ultimo aggiornamento: 19 ottobre 2025

{{BRAND}} esegue le conversioni dei file interamente nel tuo browser. I tuoi file non vengono mai caricati sui nostri server. Di seguito spieghiamo come proteggiamo gli utenti e l’app stessa.

Modello di minaccia & filosofia

  • Minimizzazione dei dati: file e contenuti sensibili restano sul tuo dispositivo.
  • Sicurezza del trasporto: tutte le pagine sono servite su HTTPS con HSTS abilitato.
  • Isolamento: ove possibile, le elaborazioni pesanti usano WebAssembly/Web Workers per mantenere i task in sandbox nel browser.

Pratiche di sicurezza applicativa

  • Content Security Policy (CSP): impostazioni predefinite restrittive per limitare le origini degli script e il codice inline.
  • Subresource Integrity (SRI): script/stili di terze parti protetti con attributi di integrità, ove applicabile.
  • Intestazioni: COOP/COEP/CORP e Permissions-Policy per ridurre i rischi cross-origin e limitare le API potenti.
  • Supply chain: aggiornamenti delle dipendenze tracciati e patch di sicurezza applicate tempestivamente.
  • Sandboxing degli annunci: gli spazi pubblicitari usano dimensioni fisse e iframe in sandbox per minimizzare lo spostamento del layout (layout shift) e ridurre il rischio.

Nota: le policy esatte possono variare in base alla distribuzione; se sei un ricercatore, contattaci per i dettagli.

I tuoi file & dati

  • Nessun upload: le conversioni avvengono localmente nel tuo browser.
  • Nessuna conservazione: non archiviamo i tuoi file sui nostri server.
  • Solo annunci & consenso: possiamo trattare identificatori limitati per erogare e misurare gli annunci, in base alle tue preferenze di consenso. Vedi la nostra Informativa sulla privacy.

Divulgazione delle vulnerabilità

Se ritieni di aver trovato un problema di sicurezza, invia un’email a {{SECURITY_EMAIL}} con i dettagli. In caso di responsible disclosure, confermeremo la ricezione e lavoreremo per risolvere rapidamente il problema.

Opzionale: pubblichiamo anche /.well-known/security.txt con i nostri contatti aggiornati.

Disponibilità del servizio

Essendo uno strumento in-browser, {{BRAND}} dipende dalle prestazioni del tuo dispositivo e dalle capacità del browser. Miriamo a supportare le versioni attuali dei principali browser su desktop e mobile.
