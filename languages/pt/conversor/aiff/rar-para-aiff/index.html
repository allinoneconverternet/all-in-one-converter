Resultados

Início rápido

  1. Adicionar ficheiross: arraste e largue na caixa ou clique em Adicionar ficheiross.
  2. Escolher saída: selecione um formato em Converter para (defina a Qualidade para JPEG/WebP).
  3. Converter: clique em Converter. A linha mostra uma insígnia, o progresso e o estado.
  4. Transferir: quando o estado for Pronto, clique no nome do ficheiro para descarregar esse resultado. Utilize Guardar tudo para guardar todas as saídas de uma vez.
  5. Remover: clique no × num ficheiro para o remover da lista.

Dicas

  • Conversões em paralelo: ajuste quantas correm em simultâneo.
  • Orçamento de memória: mude para Manual se atingir limites.
  • Nomes longos: os nomes são encurtados no cartão; passe o rato para ver o nome completo.
  • Privacidade: tudo corre no seu navegador — sem envios.

Capacidades detetadas

AIFF

Áudio PCM não comprimido comumente usado em sistemas macOS.

Converter para AIFF

AIFF armazena áudio não comprimido similar ao WAV, oferecendo excelente qualidade e edição simples. É popular em fluxos Apple e DAWs antigas. Para distribuição ou nuvem, considere converter para AAC/MP3/Opus para reduzir tamanho sem regravar.

Converter de AIFF

Converter de AIFF para WAV preserva a qualidade para edição multiplataforma. Para compartilhar, escolha um codec moderno com perdas em bitrate apropriado, ou FLAC para compressão sem perdas.
